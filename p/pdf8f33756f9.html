GitStock

Free git commit history visualizer and GitHub Trending archive

Category: Developer Tools | Tags: #git #github #commit-history #readme | Listed: 2026-11-22

GitStock is a free web tool for developers. Enter a public GitHub repo (owner/repo) and it charts the latest 100 commits as an interactive candle-style activity chart you can share as an SVG, image, Markdown or HTML README embed, or MP4. Public repos only, no login. Also includes a GitHub Trending archive and a keyless trending JSON API.
