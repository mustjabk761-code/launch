OpenPWA Demo

Installable demo of five PWA capabilities, with feature detection and the code shown

Category: Developer Tools | Tags: #pwa #web apps #javascript #web platform | Listed: 2026-11-11

A free companion web app for openpwa.net. It tries five PWA capabilities in your browser: install, Web Share, app badging, push permission and file handling. For each one it runs feature detection, shows the exact code being run and prints the result, so developers can check what their browser supports.
